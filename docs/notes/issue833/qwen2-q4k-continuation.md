# Qwen2 Q4_K chunked-prefill continuation

Issue #833's Qwen2-0.5B Q4_K_M reproducer uses a 429-token natural prompt and three fixed continuation tokens. The previous 128-token chunked run had a maximum prefill-logit difference of 0.438 and only 3/24 exactly matching KV layers against uninterrupted prefill. Ordinary generation was not shown to be broken.

At token 131, layer 2 MLP down projection, the captured FP32 input and pinned Q4_K weight matrix were replayed through the loaded Q8_K quantizer and projection providers. The Q8_K row SHA-256 was `acaaa7f59de4dd5a2aa9bcad15cadfb19e3eaa8cb0774c1f9c505bfabb1469c4` on both ARM and x86. On the captured input, one-row GEMV differed from the four-row prefill projection in 833 of 896 output channels, maximum absolute difference `2.5331974029541016e-7`. The new one-row prefill-order entry matched the four-row result exactly. This is a reduction-order difference on identical operands, not evidence of a different cache owner or token position at this projection.

The compiler selects the entry only when the chosen prefill map declares the same Q4_K/Q8_K provider, weight, activation/output buffers and reduction contract. It forwards a declared projection bias, or passes null for a bias-free projection. The first intermediate chunk is aligned to that provider's four-row group. The ordinary decode provider remains unchanged. The later chunks use the history-safe continuation path.

The adjacent JSON reports compare uninterrupted prefill with chunk sizes 127 (aligned to 124 for the first chunk), 128 and 256. Each reports exact full logits, 24/24 exact KV layers and matching positions after prefill and after all three continuation steps. Reports include hashes of the weights, generated source and bundle libraries; the comparison script does not independently attest the loaded library mappings. The replay host was an ARM DGX Spark; a separate x86 leaf replay matched the four-row projection, but an x86 full-model run remains a separate acceptance gate. These results are bounded to the pinned Qwen2 artifact, prompt and execution settings. They do not certify all quantized models or mixed-request batching.

Reproduce with `version/v8/scripts/compare_chunked_prefill_v8.py --full FULL_BUNDLE --chunked CHUNKED_BUNDLE --tokens tests/fixtures/issue833/qwen2-natural-429.json --continuation tests/fixtures/issue833/continuation-3.json --json-out REPORT --require-exact`, using freshly generated bundles with the same weights and context length 1024.
